# CodeAlpha Task 1 - Simple E-commerce Store

## Structure

```text
CodeAlpha_Task1_Ecommerce/
├── frontend/
│   ├── index.html
│   ├── css/style.css
│   └── js/app.js
├── backend/
│   ├── package.json
│   └── server.js
└── README.md
```

## Backend

```bash
cd backend
npm install
npm start
```

Backend:
http://localhost:3001

## Frontend

Use VS Code Live Server on `frontend/index.html`, or another static server.

Example:
http://localhost:5500

The frontend calls the Express API at:
http://localhost:3001/api

## Features

- Product listing
- Product details
- Search
- Shopping cart
- Registration/login
- JWT authentication
- SQLite database
- Order processing
- Stock management
- Order history
